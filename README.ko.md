# TriCascade (트라이캐스케이드)

하나의 암호(패스프레이즈)로 **러시아·중국·미국의 암호 표준 세 개를 겹쳐서** 글과 파일을 잠그는 앱이에요.
모든 처리는 내 컴퓨터 안에서만 이루어지고, 인터넷으로 아무것도 보내지 않아요.

| 층 | 암호 | 나라 | 표준 |
|---|---|---|---|
| 1 | Kuznyechik (CTR) | 러시아 | GOST R 34.12-2015 |
| 2 | SM4 (CTR) | 중국 | GB/T 32907-2016 |
| 3 | AES-256 (GCM) | 미국 | FIPS 197 |

## 설치와 실행

```bash
pip install -r requirements.txt
python tricascade.py
```

Python 3.9 이상이 필요해요. 브라우저가 열리면 메시지와 패스프레이즈를 넣고 **Lock message**를 누르세요.
받는 사람은 잠긴 글을 붙여 넣고 같은 패스프레이즈로 **Unlock message**를 누르면 돼요.

## 이럴 때 쓰세요

- 복구 코드, 계정 정보 같은 메모를 안전하게 보관할 때
- 일반 메신저나 이메일로 민감한 내용을 보낼 때 (패스프레이즈는 전화나 대면 등 **다른 경로**로 전달)
- 중요한 파일을 `python tricascade.py lock -i 파일 -o 파일.tc` 로 잠글 때

## 원리 (쉽게)

1. 패스프레이즈를 `scrypt`로 오래 걸리게 변환해요. 무작위 대입 공격을 느리게 만들어요.
2. 거기서 서로 무관한 열쇠 3개를 만들어요. 한 열쇠가 알려져도 다른 층은 안전해요.
3. 메시지 길이를 32바이트 단위로 맞춰 정확한 길이를 숨겨요.
4. 러시아 → 중국 → 미국 순서로 세 번 잠가요. 가장 바깥 AES가 위조 여부도 검사해요.

## 정직한 한계

- 안전의 대부분은 **패스프레이즈 강도**가 결정해요. `python tricascade.py gen`으로 만든 것을 쓰세요.
- 세 겹이 AES 하나보다 눈에 띄게 강해지는 것은 아니에요. 한 층에 결함이 발견돼도 나머지가 지켜주는 **이중 안전장치**예요.
- 독립적인 보안 감사를 받지 않았어요. 생명이나 재산이 걸린 비밀에는 쓰지 마세요.
- 암호 소프트웨어의 사용 규정은 나라마다 달라요. 거주 국가의 법을 확인하세요.

`python tricascade.py selftest`를 실행하면 세 암호가 공식 시험값과 일치하는지 직접 확인할 수 있어요.
